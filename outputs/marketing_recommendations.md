# Marketing recommendations (simulated data)

**Read this first:** all numbers come from simulated data. They show how the method works, not facts about real brands.

Each action has evidence (from the comments), a P2 budget note, and a metric to check after the test.

## Instagram

- **Project 2 (paid ads):** ROAS 6.02, recommended budget Rs. 246,000 (25% of Rs. 1,000,000)
- **Project 1 (organic, public dataset):** median 36 likes per post, rank 2 of 5 platforms
- **Project 3 (this project):** best content type here is **Reel**; 55 of 1326 posts (4.1%) flagged as unusual

### Instagram / 11.11 Sale

_P2: ROAS 8.5 in this campaign vs 6.0 on Instagram overall (strong campaign for this platform); budget share 25%_

1. **Content: Price-inquiry shoppers** (19% of comments)
   - Action: Put the price in the first line of the caption and in a pinned comment, so people do not need to ask.
   - Check with: number of 'price?' comments per 100 comments

2. **Promotion: Discount seekers** (16% of comments)
   - Action: Run a time-limited discount code and announce it in the post, so the question is answered before it is asked.
   - Check with: code uses; discount-request comments per 100 comments

3. **Promotion: Price-sensitive critics** (6% of comments)
   - Action: Test a value message (bundle, 2-piece offer, fabric proof) instead of a plain price cut.
   - Check with: share of negative price comments; sales of the bundle

## Limits

- Data is simulated. Segments, ROAS and flags show the method, not the market.
- ROAS is not profit, and expected revenue assumes ROAS stays the same when spend changes.
- Comments show what people say, not why. Every action is a TEST to run for a few weeks, not a proven fix.
- Project 1 data is a public dataset (not Pakistani brands) and Project 2 / 3 data is simulated, so the three projects are joined by method and by platform / campaign names, not by the same real customers.
